# Janus — S1 Spec: Reproduce + Triage (suggest mode)

Source of truth: `PLAN.md` §1.2, §1.3 and §5 (S1), implemented via
`docs/IMPLEMENTATION_PLAN.md` §2 **Phase 4** and §1.4. This spec is the contract for
milestone **S1**.

S1 stops at a **diagnosis**: Janus reruns the failing targets, scores seven signals, picks a
route, and posts an evidence comment (or Check update). It does **not** fix anything. Only
`CODE_BUG` would proceed to a fix — and that loop is S2, not here.

This document freezes the **shared data types** (`janus/core/evidence.py`,
`janus/core/triage/routes.py`, `janus/core/signals/base.py`) and the **decision rule**, so
the reproducer, the seven signal collectors and the scorer can be built in parallel against
one stable interface.

**Status: implemented (Phase 4 / S1).** The frozen types above exist, and so do the pieces
built against them: the reproducer (`janus/core/reproducer.py`), the seven collectors
(`janus/core/signals/**`), the scorer (`janus/core/triage/scorer.py`), the evidence renderer
(`janus/report/comment.py`), the `.janus.yml` loader (`janus/config/janus_yml.py`), the
pipeline wiring in `janus/jobs/processor.py`, and the S1 seed repo
(`tests/fixtures/sample_repo/`). The fix loop remains S2 (§6).

---

## 1. Scope

**In scope (S1):**

- **Reproduce.** Rerun the failing targets **K = 5** times in the rootless Docker sandbox,
  then run the **full suite once**. Two profiles: `clean` (deterministic) and `ambient`
  (matches the failed run's image/env; falls back to clean and records
  `ambient_reconstructed = False` when it cannot be reconstructed).
- **Evidence surface.** The frozen `Reproduction` / `RunAttempt` / `ChangeSummary` /
  `CommitSummary` types (`janus/core/evidence.py`). These carry *measured facts* and never a
  verdict.
- **The seven signals.** `determinism`, `signatures`, `exit_codes`, `resources`,
  `change_attribution`, `correlation`, `flake_history`. Each collector returns a
  `SignalEvidence` (summary, details, per-route votes) or `None` to abstain.
- **The scorer.** Weighted aggregation of the signal votes into the three real routes, then
  the `tau`/`epsilon` decision rule.
- **The decision rule.** `janus/core/triage/routes.py`: `Route` (`CODE_BUG`, `FLAKY`, `ENV`,
  `UNSURE`), `decide(...)`, `DEFAULT_TAU = 0.80`, `DEFAULT_EPSILON = 0.05`,
  `DEFAULT_WEIGHTS`.
- **Comment-only routes.** `FLAKY`, `ENV` and `UNSURE` never proceed; `COMMENT_ONLY_ROUTES`
  encodes that. Only `CODE_BUG` would proceed (in S2).
- **Config.** `.janus.yml` / settings for `K`, `tau`, `epsilon`, weights, and cost caps.
- **Cost caps.** Per-failure sandbox-minute cap; exceeding it degrades to comment-only.

**Non-goals (see §6):** the fix loop (SBFL/bisect, retrieval, LLM diff, proof/policy gates,
PR mode) is **S2** and lives in `docs/specs/S2.md`. Nothing in `PLAN.md` §3 may start.

## 2. Data model (frozen types)

### 2.1 `janus/core/evidence.py` — measured facts

| Type | Fields | Meaning |
|---|---|---|
| `RunAttempt` | `index`, `target_id: str \| None`, `passed`, `duration_s`, `exit_code: int \| None`, `timed_out`, `oom_killed`, `cpu_seconds`, `peak_mem_mb`, `stdout_excerpt`, `stderr_excerpt`, `sandbox_error: str \| None = None` | One run of one target (`target_id` `None` = the full-suite run). Excerpts are redacted and bounded. |
| `Reproduction` | `profile: Profile`, `attempts: tuple[RunAttempt, ...]`, `full_suite: RunAttempt \| None`, `ambient_reconstructed: bool = True`, `cost_minutes: float = 0.0` | The whole reproduction phase. Derived: `failures`, `successes`, `failure_rate()`, `always_fails()`, `intermittent()`, `passes_always()`, `total_duration_s`. |
| `CommitSummary` | `sha`, `message`, `files: tuple[str, ...]` | One commit in the last-green → first-red range. |
| `ChangeSummary` | `base_sha: str \| None`, `head_sha`, `commits`, `files_changed`, `diff_excerpt`; property `available` | What changed between the last green run and the first red one. `available` is `False` when `base_sha is None`. |

`Reproduction` helper semantics (all defined on the dataclass):

- `failures` / `successes` count the reruns in `attempts`.
- `failure_rate()` = `failures / len(attempts)`, and **`0.0` when there are no attempts**.
- `always_fails()` = at least one attempt and all failed; `passes_always()` = at least one
  attempt and all passed; `intermittent()` = both a pass and a failure. **All three are
  `False` for an empty `attempts`** (never vacuously true).
- `total_duration_s` = sum of attempt durations **plus** `full_suite.duration_s` when present.

### 2.2 `janus/core/triage/routes.py` — vocabulary + decision rule

| Name | Value / meaning |
|---|---|
| `Route` | `StrEnum`: `CODE_BUG`, `FLAKY`, `ENV`, `UNSURE`. |
| `TRIAGE_ROUTES` | `(CODE_BUG, FLAKY, ENV)` — the three scored routes, in **tie-break order**. |
| `COMMENT_ONLY_ROUTES` | `frozenset({FLAKY, ENV, UNSURE})` — only `CODE_BUG` proceeds. |
| `SIGNAL_NAMES` | the seven signal names (stable dict keys). |
| `DEFAULT_TAU` | `0.80`. |
| `DEFAULT_EPSILON` | `0.05`. |
| `DEFAULT_WEIGHTS` | the seven signal names → weights (see below). |
| `TriageDecision` | `route`, `confidence`, `top2_gap`, `scores: Mapping[Route, float]`, `reasons: tuple[str, ...]`. |
| `decide(scores, *, reasons=(), tau=DEFAULT_TAU, epsilon=DEFAULT_EPSILON)` | the decision rule. |

**Decision rule (`PLAN.md` §1.2).** Take the argmax over the three real routes. `UNSURE`
when the top score is `< tau` **or** the top two are within `epsilon`; otherwise the argmax
route. `confidence` = top score, `top2_gap` = top-two difference, `reasons` = the caller's
reasons plus the rule's own justification. **Ties resolve deterministically** to the earlier
route in `TRIAGE_ROUTES` order (`CODE_BUG` > `FLAKY` > `ENV`); with the default `epsilon`,
a tie also falls to `UNSURE` because `top2_gap = 0 < epsilon`.

**Default signal weights** (sum `1.0`):

| Signal | Weight | Why |
|---|---|---|
| `determinism` | `0.22` | always-fail vs intermittent separates CODE_BUG from FLAKY. |
| `signatures` | `0.18` | timeout / ECONNRESET / 429-503 / ENOSPC / OOMKilled / SIGKILL / resolver errors identify an infra break. |
| `change_attribution` | `0.16` | a diff between last green and first red is direct CODE_BUG evidence. |
| `exit_codes` | `0.14` | the coarser taxonomy behind signatures (137, 124, 1, 2). |
| `correlation` | `0.10` | matrix leg / cache miss / runner → ENV. |
| `flake_history` | `0.10` | per-test historical rate → FLAKY. |
| `resources` | `0.10` | cgroup CPU/mem/IO, wall-clock vs baseline. |

These are defaults; the scorer may take overrides from `.janus.yml`.

### 2.3 `janus/core/signals/base.py` — the collector contract

| Name | Meaning |
|---|---|
| `SignalEvidence` | `name`, `summary`, `details: Mapping[str, Any]`, `votes: Mapping[Route, float]`. A missing route in `votes` means `0`; `UNSURE` is never voted. |
| `SignalContext` | the inputs every collector may read: `reproduction: Reproduction`, `change: ChangeSummary`, `failing_targets: tuple[str, ...]`, `flake_history: Mapping[str, float]` (target id → historical failure rate), `metadata: Mapping[str, Any]` (CI correlation facts: runner, matrix leg, cache hit, …). |
| `Collector` (Protocol) | `name: str` and `collect(ctx) -> SignalEvidence \| None`. **`None` means "no evidence available"** (abstain), not "vote zero". |
| `clamp_votes(votes)` | drops `UNSURE` and clamps the rest into `[0, 1]`; the one place that guarantees a collector cannot invent an `UNSURE` vote. |

## 3. Data model rows (Postgres, from `IMPLEMENTATION_PLAN.md` §1.4)

The frozen types materialise into these existing rows (schema owned by Alembic; **not** edited
by this spec's implementation wave):

| Table | Purpose | Key fields | Fed by |
|---|---|---|---|
| `reproductions` | rerun evidence | `job_id`, `profile`, per-run result, exit code, telemetry JSON | `Reproduction` / `RunAttempt` |
| `signals` | scored evidence | `job_id`, `signal_name`, `raw`, `normalized`, `weight` | `SignalEvidence` |
| `diagnoses` | triage outcome | `job_id`, `route`, `confidence`, `top2_gap`, `evidence JSON` | `TriageDecision` |

Route (`CODE_BUG`/`FLAKY`/`ENV`/`UNSURE`) lives on `diagnoses`, **not** on the queue state.

## 4. Acceptance criteria (Phase 4)

From `IMPLEMENTATION_PLAN.md` §2 **Phase 4**:

- A seed repo with a **logic bug**, a **flaky test** and an **infra break** is labeled
  **differently** with evidence.
- A **confusion matrix** over the seed set is sensible.
- **`UNSURE` comments only** (as do `FLAKY` and `ENV`).
- **Thresholds are configurable** (`K`, `tau`, `epsilon`, weights, caps).

Interface-level acceptance (types + rule):

- `uv run pytest tests/unit/test_evidence.py tests/unit/test_triage_routes.py tests/unit/test_signals_base.py -q`
  is green.
- The seven signal names are exactly `SIGNAL_NAMES`; `DEFAULT_WEIGHTS` covers them and sums
  to `1.0`.
- `decide` returns the argmax above `tau` and outside `epsilon`, and `UNSURE` below `tau` or
  within `epsilon`; ties are deterministic.
- `clamp_votes` drops `UNSURE` and clamps to `[0, 1]`.

## 5. Config (`.janus.yml`) and cost caps

Per-repo behaviour (defaults; env/infra settings stay in `janus/app/config.py`):

```yaml
mode: suggest            # suggest (default) | pr   — pr is S2
reproduce:
  k: 5                   # reruns of each failing target
  profiles: [clean, ambient]
  full_suite: true       # run the whole suite once at the end
triage:
  tau: 0.80
  epsilon: 0.05
  weights:               # must sum to 1.0; omit to use DEFAULT_WEIGHTS
    determinism: 0.22
    signatures: 0.18
    change_attribution: 0.16
    exit_codes: 0.14
    correlation: 0.10
    flake_history: 0.10
    resources: 0.10
caps:
  max_sandbox_minutes: 30   # per failure; exceeding it → comment only
```

**Cost caps (`PLAN.md` §4).** The per-failure sandbox-minute cap bounds the whole
reproduction; exceeding it (or a per-repo daily budget) degrades to **comment only**, never
a fix. `Reproduction.cost_minutes` carries the measured spend for accounting.

## 6. Out of scope

- **The fix loop** — localization (SBFL → ranked `file:line`, then `git bisect`), retrieval
  (`git log -p` grep), LLM source-only diff generation, the four proof gates, the policy
  gate, retries and PR mode. All **S2**; see `docs/specs/S2.md`. (`git bisect` is deferred:
  the source clone is `--depth 1`, so there is no history to bisect — ADR D-070.)
- Anything in `PLAN.md` §3 (flake quarantine PR, pipeline self-heal, graduation, trained
  classifier, Node adapter, Temporal, vector RAG, dashboard, gVisor, hosted deployment).
